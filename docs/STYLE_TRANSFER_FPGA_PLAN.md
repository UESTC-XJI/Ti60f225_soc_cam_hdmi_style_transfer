# 莫奈单风格网络到 FPGA Demo：执行方案

本文件替代原先的 CycleGAN 教师与融合引擎设想。实际训练、导出和 RTL 已实现，验收记录见 `STYLE_DEMO_IMPLEMENTATION.md`。目前目标是单风格简单 Demo；双风格切换与 720p 网络推理属于后续工作。

## 1. 赛题与当前边界

网络使用普通卷积、深度可分离卷积、固定统计 BN、ReLU、残差连接及 nearest 上采样。FPGA 实际计算卷积和 BN 仿射，不部署教师或 VGG。相机 1080p 输入全幅 3×3 面积平均得到 640×360，上下补 60 行黑边凑 640×480。HDMI 输出 1280×720@60Hz；显示端只取活动行：对比模式左侧完整原画、右侧完整风格画（等比、上下各 180 行黑边），单画面为风格 320×180 4× 铺满全屏。

采集、推理、显示是三个不同计数。15 fps 是待验证的最低演示吞吐，30 fps 是进一步目标。HDMI 60Hz 会重复结果帧，不能报告为网络 60fps；六帧缓冲满时丢弃输入并计数，不声称长期处理 30fps 全部输入。

当前数据是标签及抽样符合莫奈的绘画/照片非配对数据，不能把它称作已核实的梵高数据。单风格 Demo 不等于双风格、高阶全部赛题验收。

## 2. 数据与训练

数据根目录：`../archive`。原始图像和 metadata.csv 保持不变。以实际目录枚举、RGB 哈希和 dHash≤4 的连接组建立新清单；跨原始 train/test 的近似组全部保留为 test。分组使用五个桶筛选候选，不是人工穷尽场景泄漏认证。

最终 `reports/style_demo/data_v2/manifest.json`：A 域 968/102/123，B 域 5500/616/922，分别为 train/validation/test。八张 trainA 绘画的平均 VGG Gram 是固定风格目标；照片和画作不能按编号作为配对真值。

教师采用感知式 Fast Neural Style 网络，而非 CycleGAN：2500 steps、batch6，内容 VGG +1500×Gram +0.03×TV，得到 `teacher_v2/step_002500.pt`。学生从教师蒸馏，8000 steps、batch12，采用 QAT 前第 5000 步作为 FP 基准。早期 QAT 曾出现输出塌缩，已修复 fake quant 夹紧区的 STE 梯度，并重新微调；该失败候选不用于部署。

最终从 FP 第 5000 步恢复，冻结 BN，使用冻结 FP 学生为参考做 3000 steps QAT，batch12、lr5e-5，损失 0.1×content +50×L1 +0.03×TV，style 项为 0。采用 `qat_recovery/step_003000.pt`。旧 checkpoint 的 loss 描述字符串保留原文以维持 SHA256，应按实际参数字段和本记录理解。

## 3. 部署网络

C24/R4：8251 个训练参数、23 个卷积、22 个 BN，640×480 约 204.13M MAC。

| 阶段 | 运算 | 输出 |
|---|---|---|
| E1 | 3×3 Conv 3→8，stride2，BN/ReLU | 320×240×8 |
| E2 | 3×3 DW8，stride2；PW8→24，BN/ReLU | 160×120×24 |
| R1～R4 | DW24→PW24→DW24→PW24，BN、残差、ReLU | 160×120×24 |
| D1 | nearest2；DW24；PW24→8，BN/ReLU | 320×240×8 |
| D2 | nearest2；DW8，BN/ReLU；PW8→3，线性/clip | 640×480×3 |

全部 3×3 为 zero padding=1。中间激活 scale=1/16，输入及输出 scale=1/128，RGB 转换 `q=u8-128`。权重逐输出通道对称 INT8；残差支路尺度相同。完整有效载荷 11056 bytes；96 字节宽银行化镜像 24576 bytes，不以纯卷积权重大小代替片上 RAM 消耗。

## 4. 定点与 RTL

NumPy 独立参考采用 INT32 卷积、INT64 仿射，最近舍入且半值远离零、INT8 饱和。BN 常数为 signed16 M、signed32 B、shift8，实际执行 `acc*M+B` 后舍入；RGB head 不伪装为训练 BN。

共享引擎为 8 输出×12 归约项的 96 路 INT8 乘法，流水归约、显式 BN、残差、背压。普通 RGB 3×3 至多 27 个非零项，`abs(acc)≤442368<2^19`；实现中 20 位累加精确等价于 INT32，36 位仿射覆盖任意 signed16 M/signed32 B。导出模型实际仿射上界为 13335729260。通用 MAC 测试模块仍支持 32/48 位参数。

三条输入行按通道/最大宽度分别分配 RAM，残差仅在 160 宽使用。权重与 BN 共用单读口 RAM，组 1/2 的 BN 首个像素读后缓存；PW 直接使用同步行读数据，减少一个等待拍。

当前实现是逐层 DDR 调度，尚未实现先前设想的多层融合；不得沿用原来的 18.10ms 理想 MAC 发射时间作为实测帧耗时。CNN 为 148.5MHz，DDR/APB 为 100MHz，HDMI 为 74.25MHz。五个 AXI 通道通过 Gray 指针异步 FIFO 传输，任务与完成采用稳定邮箱/切换位。

## 5. 集成与地址

独立分支 `codex/monet-style-demo`，工作区 `../Ti60f225_soc_cam_hdmi_style_demo`，基线提交 `85439b8`。原工作区保持原样。保留 CSI、Debayer、软件 3A、Sapphire、DDR、OSD、启动彩条；新视频系统替换缩放/帧缓存/CVO 路径。

| 区域 | 地址 |
|---|---|
| 六个 raw 槽 | 0x05000000 + slot×0x140000 |
| 六个结果槽 | 0x05800000 + slot×0x140000 |
| 中间张量 | [0x06000000,0x06400000) |
| CNN APB | 0xf8100200～0xf81002ff |
| 完成中断 | PLIC source16，userInterruptA |

每槽有效帧 0x12c000 bytes。原帧区 [0x04000000,0x04A8C600) 不覆盖。特征 DDR 使用寿命安排允许 D2 的大张量覆盖已经死亡的 F2/BIG 区，地址表见 `rtl/style/model/program.json`。

六个成对槽遵循 FREE→CAPTURE→READY→INFER→COMPLETE→DISPLAY。完成 B 响应后入 READY FIFO；单任务推理完成顺序固定，最新结果指针选择显示帧，避免串行帧号比较的长时序路径。显示切换等待垂直帧事件和读 DMA 安全点；原画与结果共享 slot。

CPU 开机加载 6144 个系数 word，等待 CDC 提交计数相同；运行 32×24 完整网络自测，经 PLIC ISR 返回后逐字检查 DDR 结果，再打开流。自测失败保持彩条/停机。固件需按既有 DDR 校准后的下载方式运行，当前 bootloader 不自动加载本应用。

## 6. 验证与交付门槛

1. 保留训练/验证日志、模型及数据 SHA256；最后只使用保留 test 做评估。
2. MAC、23 层逐行、完整小图、完整 VGA 与 NumPy 整数逐字对拍，覆盖随机停顿、边界、残差、上采样。
3. 覆盖 APB 权重提交、busy 写拒绝、中断 W1C、异步复位、AXI 错误、两级 CPU/CNN/video ID 恢复。
4. 检查裁剪四像素平均、队列满/错误回收、720p 三帧完整时序、左右配对、DDR 饥饿后的黑屏和恢复。
5. 构建实际 ELF，用 RV32 指令仿真检验启动、PLIC 驱动、中断保存/恢复与自测；外设/缓存模型不等于 Sapphire RTL或实板。
6. Efinity 完整顶层综合、接口、布局布线、setup/hold 及配置文件生成；工具 PASS 不自动等于时序 PASS。
7. 无板卡时交付可审查源码、权重、固件、仿真与构建记录。实板 MIPI、DDR 效率、推理 FPS、延迟和视频画质保持待测。

后续只在资源/时序有余量后讨论融合、双风格权重和 720p。先补实拍曝光/白平衡及真实相邻视频测试；当前合成 4 像素平移等变结果不能替代视频稳定性验收。
