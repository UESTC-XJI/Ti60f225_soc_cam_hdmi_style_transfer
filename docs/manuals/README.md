## 已从中确认、写进代码和文档的关键数据

### 增益寄存器（§2.3，表 2-6 / 2-7 / 2-8）
| 寄存器 | 作用 | 范围 |
|---|---|---|
| `0x3E08` | 模拟增益粗调（**bit[7] = DCG 开关**）| — |
| `0x3E09` | 模拟增益细调（步进 ≈ ×1.031）| — |
| `0x3E06` | 数字增益粗调 | — |
| `0x3E07` | 数字增益细调（精度 1/32）| — |

- 模拟增益范围 **1.000× … 48.510×**（178 档，表 2-7）
- 数字增益表内 1.000× … 10.750×（表 2-8），规格标称上限 16×
- 常用档位：`0x83/0x20` = 6.160×（原值）· `0x83/0x3A` = 11.165×（2026-10-28 起）·
  `0x83/0x3E` = 11.935× · `0x83/0x3F` = 12.128×

### AGC 策略（§2.4.1）——直接引原文
> 「调整策略为：**曝光时间优先，曝光时间已经最长无法继续调整时，调整增益**」
> 「1) 不开启任何增益，直到曝光时间达到上限；2) 曝光时间达到上限后，再开始调用自动增益控制」

### 噪声（§2.4.1）——加增益的代价
> 「需要明确指出的是，**增益开启，将直接导致平均噪声呈倍数放大**；而曝光时间加大，则有助于提升信噪比。」

⇒ **加一档增益 ≈ 噪声翻倍**。曝光换亮度比增益换亮度干净，这是"曝光优先"的物理原因。

### 帧率与曝光上限
- `最大图像传输速率 2560(H)×1440(V) @ 30/60 fps` ⇒ **1080p 原生支持 30 fps**
- 线性模式曝光上限 = `2 × VTS − 11`，单位是**半行**
- 寄存器 `0x3E00/0x3E01/0x3E02` = 曝光（半行），`0x320E/0x320F` = VTS（行）

### 两个操作约束（§2.4.2）
- **增益第 N 帧写入、第 N+2 帧生效**（AGC 控制环要按 2 帧延迟设计）
- 线性模式下建议在**帧开始之后**写入曝光/增益

## 其他有用规格
- 灵敏度 4319 mV/lux·s，信噪比 38.47 dB，线性模式动态范围 81 dB（HDR >100 dB）
- 输出 RAW RGB，8/10-bit，1/2/4-lane MIPI
- `0x3E10/0x3E11` = HDR 短曝光增益，`0x3E12/0x3E13` = HDR 短曝光时间
  （⚠ 注意：`0x3E16~0x3E19` 属于 HDR 寄存器区，**不是**第二组数字增益——2026-10-27 曾误判过）
