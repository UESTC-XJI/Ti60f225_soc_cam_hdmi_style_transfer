## 外部DDR容量和带宽

FPGA内部135块存储与板载DDR帧缓存是不同资源。摄像头保持1080p，缩放后720p图像以32位 `0x00BBGGRR` 保存；每帧3,686,400字节，三帧11,059,200字节（约10.55MiB，另考虑地址对齐）。起点保存1080p RAW8，三帧有效数据仅6,220,800字节，因此本版分辨率下降而DDR容量增加。

720p60单路读取有效带宽221.184MB/s；若摄像头也是60fps，读写合计442.368MB/s，不含命令/刷新/总线开销。传感器实际帧率需上板测量，不能直接等同HDMI60Hz。后续SoC应共享DDR仲裁和划分地址空间，不能简单相加两个含DDR的例程资源。
