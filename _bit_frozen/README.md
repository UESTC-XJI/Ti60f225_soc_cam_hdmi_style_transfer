# 冻结位流 —— 测固件期间的"已知良好"基准

**谁用**：模型侧 / 任何要反复烧固件的人。
**为什么**：每烧一次 ELF 都会锁存采集故障（`CAP 0 / NN 0`、屏幕黑），
恢复必须**重配 bit**。而重配默认读 `outflow/ti60f225_oob.bit` ——
那个文件会被下一次 `_b.bat` 构建覆盖。锁定副本后，无论别人怎么构建，
你的恢复流程都稳定。
