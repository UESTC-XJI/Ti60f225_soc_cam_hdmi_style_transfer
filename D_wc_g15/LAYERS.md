# `deploy` —— 改D-Y: 1/8ch 3res 3x3 亮度域

> 本文件由 `tools/spec_md.py` 从 `spec.json` 生成，**别手改**。

## 输入 / 输出

- 输入形状 `[1, 1, 64, 64]`，通道数 **1**
- 说明：单通道亮度 Y [0,1]（BT.601），色度不经网络、部署端原样接回；边长需为 4 的倍数（编码器 ceil、解码器 x2 不对称）

## 量化

- **weight**：int8 对称，逐张量 per-tensor
- **activation**：uint8 非对称，ReLU 后非负故 zero-point 恒为 0
- **accumulator**：int32

- 权重总字节 **16776 B**，偏置 **137** 个 int32

> ⚠ **约束**：残差相加的两条分支必须共用同一条激活 scale

## 权重 / 偏置布局

- `weight_layout`：`cout x cin x k x k，行主序`
- `bias_quant`：`int32，值 = round(b / (activation_scale_in * weight_scale))`
- ⚠ `weights.hex`（int8）与 `biases.hex`（int32）是**两个文件**，各自有独立偏移；层记录里的 `weight_offset` / `bias_offset` 是**各自文件内**的偏移。
