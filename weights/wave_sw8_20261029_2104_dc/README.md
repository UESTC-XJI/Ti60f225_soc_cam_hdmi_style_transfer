# wave_sw8_20261029_2104_dc —— 板侧固化 DC 的权重

**源**：`demo/reports/rowpipe/export_wave_sw8_20261029_2104/`（模型侧导出，XOR `0x08bd471e`）
**只改了 3 个 word**：L11 的逐通道 bias。权重、M、Q 头一个字节没动。

| 项 | 原厂 | 本文 |
|---|---|---|
| L11 bias R/G/B | 1326 / 3153 / 1104 | **16685 / 17832 / 17880** |
| XOR | `0x08bd471e` | **`0x08bd0b6c`** |

## DC 标定

风格参考图：`shennaichuan.jpg`

| | R | G | B | B−R |
|---|---|---|---|---|
| 参考图（0-255） | 184.1 | 187.6 | 178.7 | -5.4 |
| 目标 q（=均值−128） | 56 | 60 | 51 | -5 |
| **实测达成** | **+56.1** | **+59.6** | **+50.7** | **-5.4** |

**方法**：目标 q = 参考图通道均值 − 128；`Δbias = Δq × 2^shift / M`。
不要"三通道归零"——那会把原厂正确的色彩平衡抹成中性灰（2026-10-27 踩过）。

- 实测 σ RGB：`39,49,57`
- 实测贴轨：`0.8%`

## 怎么用

```bash
# 构建固件（会打印 XOR 与末层约定）
bash tools/build_firmware.sh weights/wave_sw8_20261029_2104_dc/rowpipe_weights.h

# 或直接写 DDR（更快，不重烧）
python tools/style_probe.py weights weights/wave_sw8_20261029_2104_dc/rowpipe_blob.bin
```

## 注意

这是**板侧固化变体**，不是模型侧的正式导出。模型侧若重导同名风格，应以他们的新版本为准。
DC 是「每个风格 × 每个场景」的组合——换场景可能需要重新标定。
