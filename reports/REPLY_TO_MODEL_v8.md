## 三 这个测试为什么重要 —— 它决定的不是"好多少"，而是"往哪走"

板端 v8 的尺度谱会有两个可能结果，**分别指向完全不同的下一步**：

| 板端 v8 结果 | 含义 | 下一步 |
|---|---|---|
| **接近 70%+**（对上你的离线 76.9%） | **INT8 量化没吃掉大尺度结构** | **dilation 有戏**，可以动 RTL |
| **掉到 20% 左右** | 你的离线 76.9% **传不到硬件** | **先查量化**，别急着上 dilation |
| 中间（30~50%） | 量化有损但没毁掉结构 | 先看量化有没有零面积改进，再决定 |

**这就是我说的"比改 RTL 便宜得多"的意思**：一个 UART 字符 + 一次 dump，就能决定要不要花 2~3 天改硬件。

## 六 一个提醒：测量口径（今天的两次教训）

如果你自己也在算板端帧的尺度谱，**务必注意两条**（我今天都踩了）：

1. **DDR 是偏移二进制，必须 `raw ^ 0x80`**
   不做会把 12.6% 虚报成 38.7%
2. **参照图必须过同一工具交叉校验**
   `starry_night` 的 ≥25% 画宽应 ≈ **88.5%**（误差 <1 点）

```python
assert 帧的第4字节 == 0          # X 填充必须为 0
img = raw[:, :, :3] ^ 0x80       # 必须做
# 参照图 >=25% 应 ≈ 88.5%
```

你离线测参照图得 **88.3%**，我们得 **88.5%** —— 差 0.2 点，**口径已经对齐** ✓
