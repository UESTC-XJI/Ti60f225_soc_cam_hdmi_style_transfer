## 二、诊断链（全部实测，非推测）

### 发现 1：v1 的 sat 在训练中**单调上升**（推翻了我的初始假设）

| step | 250 | 500 | 750 | 1000 | 1500 | 2000 | 2500 |
|---|---|---|---|---|---|---|---|
| v1 sat | 0.058 | 0.114 | 0.174 | 0.158 | 0.177 | 0.176 | **0.197** |

**250 步时 sat 已接近目标（0.058 vs 0.042），随后一路爬升。**

**这改变了诊断**：R2 失败不是"从未达标"，而是**后期被推高**。

### 发现 2：量化项对饱和度**完全盲**（实测）

构造两张图，**逐通道亮度分布几乎相同，饱和度差 0.2203**：

| 图 | 饱和度 | R 通道分位数 |
|---|---|---|
| 灰图 | 0.0000 | [0.049, 0.250, 0.497, 0.747, 0.949] |
| 彩色图 | 0.2203 | [0.048, 0.249, 0.497, 0.749, 0.952] |

**量化损失 L1 = 0.000923**（几乎为零）。

**→ `quantile` 项匹配的是逐通道亮度分位数（`(3,L)`），对通道**间**差异是盲的。**

### 发现 3：参数级隔离 —— 所有 ablation 都让饱和**升高**

用 v1 配置跑 400 步，每次只改一项：

| variant | final sat |
|---|---|
| **sat 300 加入** | **0.0412** ✅ |
| baseline（v1 配置） | 0.0667 |
| style 0 | 0.0768 |
| identity 10 | 0.0783 |
| quantile 0 | 0.0910 |
| content 0 | 0.0995 |
| tone 0 | 0.1340 |

**每个现有项的移除都使饱和升高** → 现有项整体在**压制**饱和，
而**新增 sat 项是把饱和推到目标的那个**。

### 发现 4：sat 项单独用会产生**错误的直方图形状**

| | sat | contrast | dark% | **mid%** | light% |
|---|---|---|---|---|---|
| 水墨参考 | 0.0157 | 136.8 | 2.6% | **22.5%** | **75.0%** |
| sat 单独优化 | **0.0275** ✅ | 132.9 | 47.2% ❌ | 43.2% ❌ | 9.6% ❌ |

**饱和度达标但形状完全错**（水墨是"少量黑墨 + 大量留白"）。
**所以 sat 项必须与 quantile/contrast 配合** —— v2 正是这么用的。

## 三、v2 配置

| 参数 | v1 | **v2** | 效果 |
|---|---|---|---|
| **`--sat-weight`** | — | **300** | ✅ sat 0.202 → **0.046** |
| `--sat-target` | — | **0.0408** | A/train 469 张用损失公式实测 |
| `--cast-weight` | 0 | 0 | ✅ R1 保持 |
| `--contrast-ratio` | 0.45 | 0.45 | 防灰泥 |
| `--grain-weight` | 550 | 550 | — |
| 其余 | tone 300 / quantile 0.3 / style 1500 / identity 3 | 同 | — |

**新增项实现**（`_train_v2.py`）：
```python
mx = y.max(dim=1).values; mn = y.min(dim=1).values
sat_val = ((mx - mn) / mx.clamp_min(1e-6)).mean()
sat_loss = (sat_val - a.sat_target) ** 2       # 双侧
```

**为什么双侧**：单侧 `relu(target - sat)` 会推向全灰泥；
单侧 `relu(sat - target)` 在目标以下无梯度。**双侧 + 配对比度项**才安全。

**三种模式**：`--sat-mode mean|dark|light`（预留，v2 用 mean）。

## 四、仍存在的不足

| 项 | 状态 | 说明 |
|---|---|---|
| **mid% 64.3 vs 水墨 20.2** | ❌ **直方图形状仍不对** | 水墨是"少量黑墨+大量留白"，输出仍偏中灰 |
| **dark% 18.5 vs 水墨 9.8** | ◐ 偏暗 | 暗部过多 |
| **light% 17.2 vs 水墨 70.1** | ❌ **留白严重不足** | 这是最大剩余差距 |
| **dark-hf 0.0526 vs 0.0905** | ◐ 纹理偏低 | — |
| 笔触/留白结构 | ❌ 视觉仍不及真实水墨 | 与 v1 同 |
| 天空伪影 | ⚠️ v2 图中仍有（第二行可见亮斑） | 未定位 |

**核心剩余问题：留白（light%）只有水墨的 1/4。** 水墨的美学是"大片留白 + 少数浓墨"，
而 v2 输出是"整体中灰"。
