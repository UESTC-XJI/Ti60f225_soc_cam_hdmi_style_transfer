## 二、两项实测根因

### 根因 1：`contrast-ratio 0.45` 的目标**比真实水墨低 59%**（第 5 次同类错误）

| 集合 | lum std |
|---|---|
| **黑白ink A/train** | **0.2730** |
| photos B | 0.2510 |
| **`contrast-ratio 0.45` 的目标** | **0.45 × 0.251 = 0.1129** |

**目标 0.1129 vs 真实 0.2730 → 低 59%。**

**这正是"压向中灰"的机制**：模型被训练去**压缩**对比度，而水墨恰恰是**高对比**
（少量浓墨 + 大片留白）。

**A/B 实测确认**（400 步，用新的 24 张评估照片）：

| variant | std | contrast | **mid%** | light% |
|---|---|---|---|---|
| 水墨参考 | 0.1990 | 165.2 | **22.8%** | **70.6%** |
| **C1 `ratio 0.45`（v2 在用）** | **0.1217** | 96.7 | **78.2%** ❌ | 13.0% |
| **C2 `abs 0.2730`** | **0.2732** ✅ | 218.1 | **27.3%** ✅ | 27.3% |

**C1 的 mid 是 78.2%（水墨 22.8%）—— 这就是"太灰"。C2 修正后 mid 降到 27.3%。**

**同上一次同类错误**：曾有 `contrast-ratio` 相对形式把目标设高 56%；这次是设低 59%。
**根因相同：相对形式（×输入std）与绝对目标之间的换算没有实测。**

### 根因 2：评估与训练的验证照片**不合格**（用户指出的）

用**颜色无关**的天空检测（位置 + 平坦度，因为彩色天空会被低饱和判据漏掉）：

| 照片集 | 平均 hf | 天空主导 |
|---|---|---|
| **训练自用的 8 张**（`val[i*(len-1)//7]`） | **0.0356** | **5 / 8** ❌ |
| 旧评估用的前 8 张 | 0.0416 | 2 / 8 |
| **新建 24 张** | **~0.064** | **0 / 24** ✅ |

**训练自己的验证集 5/8 是天空主导，hf 仅 0.0356（所有候选里最低）。**

**影响**：
- 验证曲线一直在**天空图**上测 → 无法反映笔触/结构
- 我的评估用前 8 张 → 也含 2 张天空

**已修复**：新建 24 张评估集（`data_黑白ink/eval_photos.json`），按内容评分排序、排除天空主导、hf 提升约 55%。

## 三、v3 方案

### 3.1 核心改动：对比度目标改为绝对值

```powershell
--contrast-absolute 0.2730      # 实测（黑白ink A/train, 64 张用损失公式）
```
**替换** `--contrast-ratio 0.45`。

**预期效果**（据 A/B 实测）：std 0.1217 → **0.2732**，mid 78.2% → **27.3%**。

### 3.2 保留 v2 已达标项

| 参数 | 值 | 状态 |
|---|---|---|
| `--sat-weight` | 300 | ✅ sat 0.202 → 0.046 |
| `--sat-target` | 0.0408 | ✅ 实测 |
| `--cast-weight` | 0 | ✅ R1 关键 |
| `--grain-weight / target` | 550 / 0.0418 | ✅ |
| `--dark-hf-weight` | 0 | ✅ **不得重开** |
| tone 300 / quantile 0.3 / style 1500 / identity 3 | 沿用 | — |

### 3.3 评估改用新照片集

- **24 张**（`eval_photos.json`），排除天空主导
- 报告**直方图形状**（dark/mid/light），不只报 sat/std

### 3.4 是否还需要"留白项"？

**待定 —— 先看 C2 的实际效果**。

C2 的 light 只到 27.3%（水墨 70.6%），说明**对比度修正不足以产生留白**。
若 v3 实测 light 仍远低于水墨，则**需要新增留白项**。

**候选设计**（未实现，待定）：
```python
light_frac = (L > 160/255).float().mean()
light_loss = (light_frac - 0.70) ** 2
```
⚠️ **风险**：单压"亮部占比"最省力的方式是**整体提亮**（会把暗部也提亮，破坏墨）。
必须**与 dark 占比联合约束**（水墨是 dark 9.8% + light 70.6% 的双峰）。

## 五、风险

| 风险 | 说明 | 对策 |
|---|---|---|
| **只修对比度不够** | C2 的 light 仅 27.3%（水墨 70.6%） | 若 v3 的 light 仍低，**加入留白项**（联合约束 dark） |

| **对比度与 sat 冲突** | 高对比可能带回彩色 | 两者都实测；sat 项已在 |
| 目标值测错（已踩 5 次） | — | **用损失公式实测**（已做：0.2730） |
