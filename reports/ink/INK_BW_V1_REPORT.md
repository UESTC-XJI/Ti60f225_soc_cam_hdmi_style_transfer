## 三、自动流水线中我修复的两个自己的 bug

这两个 bug 导致前两次启动直接崩溃。**都是我在构建数据集时的疏漏。**

### bug 1：新数据集缺少 validation 划分

```
IndexError: list index out of range
  val = [val[i * (len(val) - 1) // 7] for i in range(8)]   # 空列表
```

**原因**：我只建了 `trainA/testA/trainB/testB`，**漏了 validation**。
而 `_train_v2.py` 硬编码从 **B/validation** 等距抽 8 张作验证集。

**修复**：B 域补 `valB`（600 张），A 域保持 train/test。

### bug 2：`style_refs.json` 缺 `trainA/` 前缀

```
FileNotFoundError: _data/黑白ink/ink_00118.jpg   # 应该是 _data/黑白ink/trainA/ink_00118.jpg
```

**原因**：我写 refs 时只存了裸文件名，而训练脚本按 `root / name` 拼接。
**可用格式**（museum）是 `trainA/ink_00296.jpg`。

**修复**：加前缀，并验证 32 条全部存在。

### 这两个 bug 的共同点

**都是"我的产物与消费者（训练脚本）的约定不一致"** ——
与本项目反复出现的"聚合/格式不一致"是同一类错误：

| # | 错误 | 类型 |
|---|---|---|
| 1 | Gram 尺度 | 度量不一致 |
| 2 | elongation 不编码笔触 | 度量无效 |
| 3 | contrast_ratio 相对形式 | 目标不可达 |
| 4 | v2 目标用不同统计量 | 度量不一致 |
| 5 | v2 std 目标无表达力 + 硬掩码死梯度 | 目标表达力不足 + 实现 bug |
| **6** | **数据集缺 validation / refs 缺前缀** | **产物与消费者约定不一致** |

**教训**：产出任何供其他脚本消费的文件，**必须先用该消费者的真实调用路径验证**。
