## 二、为什么是这几个字段

1. **平坦区 = L11 被当无符号层做 ReLU**。`requant.v:114` 用 `qlo<0` 判断是否跳过 ReLU；
   `qlo=0` ⇒ ReLU ⇒ 负半轴全夹 0 ⇒ 56% 的 DDR 字节是 0x00 ⇒ 显示端 `^0x80` 变成 128 ⇒ lift 后 ~152
   ⇒ 屏幕上一大片 `#989898`。
2. **只改 qlo 不够**：去掉 ReLU 后暴露出两件事——(a) 缩放偏大导致 70% 贴轨；(b) 直流偏置偏正。
3. **缩放**：`M/2^37 = 4.369327e-3`，单 bias 项即 278 LSB（超 8 位量程）。取 `shift=39` 后 `M/2^38` 量级才落进量程。
4. **偏置**：DDR 域的通道中心不在 0，按实测逐通道补偿（见下）。

## 四、快速迭代方法（不重烧固件）

`rowpipe_engine` **每帧都从 DDR 重读权重**，而固件的 XOR 自检只在开机跑一次。所以可直接改 DDR：

| 地址 | 内容 |
|---|---|
| `0x06F037A0 / A4 / A8` | L11 bias ch0 / ch1 / ch2（int32） |
| `0x06F03860` | L11 量化头：`{qhi[21:14], qlo[13:6], shift[5:0]}` |

```
halt → mww 0x06F03860 0x001FE027 → resume
```

一次实验约 20 秒。**注意**：连续重烧 ELF 会锁存采集故障（`FAULT 1 / CAP 0 / 3A state 7`，
`docs/PROJECT_HANDOFF.md` 有记载），只 reset CPU 清不掉，必须重新上电。

## 五、残留问题（不在显示链上）

修复后画面结构正确，但仍有：低对比度（σ 16.7 vs 原画 70）、青蓝色偏、高对比边缘有彩色条纹。

三条证据指向**模型输出标定**而非 RTL：
- 显示链逐级可验证单调、无取反（`09_ddr_byte_encoding.md`）；
- 加大缩放会把 σ 压塌（饱和），说明输出已在量程边缘，不是"显示端压缩"；
- 与 `MODEL_OUTPUT_RANGE_FIX.md` 里模型侧自报的 σ 13→23 量级一致——真实值域本就窄。

**下一步建议**：把本次采用的 L11 参数（qlo/shift/bias 语义）交回模型侧，
让他们按"零中心、目标 σ≈40~50、无逐通道偏置"重新导出 —— 这是 `MODEL_OUTPUT_RANGE_FIX.md` 方案 B 的落地。
