# 浮世绘训练效果与上板效果预判

> 日期：2026-10-14
> 方法：用**真实导出的整数网络**（板上实际跑的那份），在**真实板分辨率 640×480** 下
> 重放整条流水线，模拟采集卡会看到什么。

---

## 1. 为什么要在板分辨率下重测

之前的效果对比用的是 **256×256 + PyTorch 浮点模型**，这与板上实际情况不同：

| 项 | 之前的对比 | 板上实际 |
|---|---|---|
| 分辨率 | 256×256 | **640×480** |
| 执行 | PyTorch FP32/QAT | **纯整数 + M16/B16/shift** |
| CNN 内部分辨率 | 64×64 | **160×120** |

**所以本次用 `integer.py` 的整数 oracle 在 640×480 上重放。** 这是最接近上板真实情况的离线估算。

## 3. 上板效果预判（板分辨率 + 整数流水线）

### 3.1 效果强度

12 张验证图，640×480，整数网络：

| 指标 | Monet | **浮世绘** |
|---|---|---|
| 平均 \|Δ\| RGB | 13.17 | **13.90** |
| 平均 \|Δ\| Y | 9.27 | 11.48 |
| **比值** | 1.00× | **1.06×** |

**两者强度几乎相同**（差 6%）。这与此前 256×256 的结论一致（当时 0.784 vs 0.827）。

### 3.2 关键差异：颜色方向完全不同 ← 最重要发现

| 通道偏移 | Monet | **浮世绘** |
|---|---|---|
| **ΔR** | **−8.37**（红被压） | **+0.47**（几乎不变） |
| ΔG | +1.65 | +3.99 |
| **ΔB** | +1.87 | **+9.73**（蓝大幅提升） |

**这是两者最本质的区别**：

- **Monet**：压低红色 → 整体**去色、偏冷灰**
- **浮世绘**：大幅提升蓝色 → **明显的蓝色/青色罩染**

`+9.73` 的蓝色偏移正是浮世绘**蓝摺（aizuri-e）**配色的特征——藏青/靛蓝。

### 3.3 饱和度

| | 值 | 倍数 |
|---|---|---|
| 原图 | 0.407 | 1.000× |
| Monet | 0.278 | **0.683×** |
| 浮世绘 | 0.283 | **0.694×** |

**两者降饱和幅度几乎一样（约 −31%）。**

## 4. 上板观感预判

### 4.1 视觉上会看到什么

| 方面 | 预判 |
|---|---|
| **色调整体** | 明显**偏蓝/青**（ΔB +9.73）——这是最强信号 |
| 饱和度 | 降低约 31%，接近褪色/做旧感 |
| 对比度 | 亮度标准差约 −20% |
| 轮廓线 | **不会有锐利的版画线条**（14.8% 签名在 4× 瓶颈之上，被滤掉） |
| 细节 | 保留率约 1.10×（略增强，来自网络的纹理合成） |

### 4.2 与 Monet 的对比观感

| | Monet（当前板上） | 浮世绘（待烧录） |
|---|---|---|
| 主色调变化 | 红色被压 → 冷灰 | **蓝色提升 → 蓝青罩染** |
| 强度 | 13.17 | 13.90 |
| 饱和度 | ×0.683 | ×0.694 |
| **辨识度** | 中性、像"褪色处理" | **偏蓝，特征更明确** |

**判断**：虽然数值强度接近，但**浮世绘的蓝色偏移比 Monet 的整体去色更容易被察觉**——
人眼对色相偏移的敏感度高于等量的饱和度变化。

### 4.3 我必须如实说明的局限

| 局限 | 说明 |
|---|---|
| **这是离线模拟，不是真实采集** | 未包含相机噪声、DDR3 时序、显示链路抖动 |
| **未见真实显示器** | 实际观感受显示器色域/伽马影响 |
| **色带风险未验证** | 浮世绘平涂对量化敏感，实际可能出现 banding |
| **轮廓线预期落空** | 目视更像"蓝色调滤镜"而非"版画" |

## 6. 结论

> **训练成功，上板效果可预期为「明显的蓝色调 + 降饱和」，强度与 Monet 相当（1.06×），
> 但色彩方向截然不同（浮世绘偏蓝，Monet 偏灰），视觉辨识度更高。**
>
> **但不会出现锐利的版画轮廓线**——这部分签名（14.8%）超出 160×120 的表达能力。
>
> 真实观感需上板实测确认。
