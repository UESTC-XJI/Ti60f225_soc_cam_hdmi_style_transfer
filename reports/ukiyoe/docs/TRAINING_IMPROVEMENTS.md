## 二、我犯的两个错误（已修正）

### 2.1 identity loss 实现错了

**CycleGAN 官方定义**（`qa.md:96-106`）：

> 用 identity loss 正则化生成器，**当输入已经像目标域时保持原样**。

**正确做法**：`G_A(B)` —— 把**真实浮世绘画作**喂给"照片→浮世绘"生成器，应保持不变。

**我原先的做法**（错）：用内容图合成一个"已经带风格色调"的 proxy：

```python
proxy = (x - x_mean) * contrast + mean_target   # 错
identity = F.l1_loss(model(proxy), proxy)
```

**问题**：这个 proxy 不是真实画作，惩罚的是"生成器改动一张被人工调色的照片"，
而不是"生成器改动一张画"。**学不到"别乱改画"这个语义。**

**修正**：
```python
art = 真实 trainA 画作（500 张）
identity = F.l1_loss(model(art), art)          # 正确
```

**数据集 fortunately 就有**：`_data/ukiyoe2photo/trainA/` 有 500 张真实浮世绘。

### 2.2 色调目标用错了（仿射在暗场过亮）

**我原先的拟合**基于亮图样本：`out = 0.859·in + 45.6`

**问题**：这个拟合在**暗场**严重失准。

**全亮度范围重新拟合**（40 张图，含暗场）：

| 模型 | 公式 | R² |
|---|---|---|
| 仿射 | `out = 0.806·in + 51.6` | 0.963 |
| **二次** | `out = −0.0025·in² + 1.266·in + 32.7` | **0.980** |

**误差分带**：

| 输入 Y 区间 | 样本数 | 仿射平均误差 | 最大误差 |
|---|---|---|---|
| **0–40** | 2 | **−9.09** | **13.86** |
| 40–80 | 10 | +0.82 | 8.09 |
| 80–120 | 20 | +1.45 | 8.86 |
| 120–160 | 8 | −2.36 | 9.10 |

**具体失效点**：

```
输入 Y=15.0 -> 官方 49.8，仿射目标 63.7  （误差 +13.9）
```

**原因**：官方映射在两端都是**压缩**的（类似 S 曲线），不是直线。
暗场不会加固定 +46 LSB —— **很暗的图仍然暗**。

**修正**：改用二次目标。归一化系数换算：

```
quad  = −0.0025 × 255 = −0.6375
slope =  1.2662
bias  =  32.67 / 255  =  0.1281
```

**验证**（换算自洽）：

| 输入 LSB | 二次目标 |
|---|---|
| 15 | 51.1 |
| 102 | 135.8 |
| 204 | 186.9 |
| 255 | 193.0 |

## 五、从官方源码学到的其他关键点

### 5.1 ImagePool（`util/image_pool.py`）

判别器用**历史生成图缓冲池**（50% 概率返回旧图）：

```python
class ImagePool:
    def query(self, images):
        # 50% 返回历史图，50% 返回当前图
```

**对本项目的意义**：我们做的是**确定性风格迁移**（无 GAN 判别器），
**不需要**这个机制。**这是我们的简化优势。**

### 5.2 官方训练规模

`options/train_options.py:25-26`：

| 参数 | 默认值 |
|---|---|
| `n_epochs` | 100（初始学习率） |
| `n_epochs_decay` | **100**（线性衰减） |
| `lr_policy` | linear |
| `save_epoch_freq` | 5 |

**官方训 200 个 epoch**。以 ukiyoe2photo 的 1433 张、batch 1 计，
约 **286,600 次迭代**。

**我们只训 2500–8000 步**（约 0.9%–2.8%）。

**这是一个数量级的差距** —— 但我们的任务更简单（确定性回归 + 蒸馏，
不是双 GAN 对抗），所以不能直接类比。**但值得注意。**
