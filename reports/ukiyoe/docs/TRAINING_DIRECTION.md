# 正确的训练方向

> 日期：2026-10-14
> 依据：v1 → v7 全部版本的实测对比，以及多轮被数据推翻/修正的结论
> 性质：**纠错后的整合**，包含我犯过的错误

---

## 0. 一页结论

| 项 | 结论 |
|---|---|
| **主差距** | **调色板/平涂**（颜色多样性与色相分布），不是笔触 |
| **次差距** | 天空色相方向（蓝天未转暖） |
| **笔触** | ✅ **不是短板**，v6 的纹理频谱已接近真实浮世绘 |
| **根因** | **损失函数缺少颜色分布约束**（不是架构） |
| **架构** | ✅ 教师 RF 9，比官方 RF 7 更宽，**不需要改 RTL 或加 head** |
| **最佳版本** | **v6**（二次色调 + identity 10 + 512 分辨率） |
| **下一步** | 加**颜色分布损失**，重训教师 → 蒸馏学生 → 导出上板 |

## 2. 笔触：不是短板（推翻我之前的结论）

浮世绘是**木版印刷**，不是油画厚涂。三个特征要分开看：

| 特征 | 对应频段 |
|---|---|
| 平涂色块（木版画的平涂） | **调色板/平坦度** ← 主差距 |
| 清晰轮廓线（線） | 中频 0.08–0.25 |
| 纸/墨颗粒（紙の目） | 高频 >0.25 |

**径向频段能量实测**：

| 样本 | <0.08 | **0.08–0.16** | **0.16–0.25** | >0.25 |
|---|---|---|---|---|
| 输入照片 | 89.3% | 7.2% | 3.0% | 0.6% |
| official | 82.7% | **10.6%** | **5.3%** | **1.5%** |
| **v6** | 90.2% | **7.1%** | **2.4%** | 0.3% |
| **真实浮世绘** | 90.6% | **6.7%** | **2.3%** | 0.4% |
| 论文浮世绘图 | 87.3% | 8.8% | 2.8% | 1.1% |

**两个关键读数**：

1. **v6（7.1 / 2.4）与真实浮世绘（6.7 / 2.3）几乎一致** —— 纹理频谱是对的
2. **official（10.6 / 5.3）比真实浮世绘高一倍多** —— 官方在频谱上是**异常值**，
   它的风格感来自特有的"洗白+人造颗粒"，不是忠实还原版画纹理
3. **official 的高频（1.5%）比真实浮世绘（0.4%）还多**

## 3. 我犯过的错误（都已修正）

| # | 错误结论 | 实测修正 |
|---|---|---|
| 1 | "板书最细粒度 2×2" | ❌ **输出是完整 640×480**（上采样后有 3×3 卷积） |
| 2 | "天空改不了是第一步 stride 2" | ❌ **教师第一层是 9×9 stride 1，RF 9 > 官方 7** |
| 3 | "identity loss 修的是不存在的病，应关掉" | ❌ **它确实在压暗场**（关掉后 v7 暗场 66.3 vs v6 58.1） |
| 4 | "笔触是短板，各向异性不足" | ❌ **度量无效**（结构张量全部 ~0.75，无法区分） |
| 5 | "需要一个全分辨率 3×3 头" | ❌ **教师已够宽，head 解决不了损失问题** |
| 6 | 各向异性 1.309 / 2.846 | ❌ 粗糙全局度量的假象 |
| 7 | identity 用合成 proxy | ❌ 应喂**真实浮世绘画作**（trainA 500 张） |
| 8 | 仿射色调目标 | ❌ 暗场失准，应用**二次**（R² 0.963 → 0.980） |
| 9 | DDR"固定槽位"模型 | ❌ 四个缓冲**有意重叠**（alias） |

## 5. 根因：损失函数缺少颜色分布约束

### 5.1 现有损失项的覆盖范围

| 损失项 | 约束什么 | 能否影响调色板 |
|---|---|---|
| content | VGG relu3_3（结构） | ❌ |
| style | 加权 Gram（二阶纹理统计） | ◐ 很弱 |
| **tone** | **仅全局 mean + std** | ❌ **均值/方差不含直方图** |
| identity | G(画作) ≈ 画作 | ◐ 只防改动 |
| **（缺失）** | **颜色直方图 / 分位数** | **← 关键** |

**均值只约束"平均亮度"，标准差只约束"整体对比度"。**
两者都无法表达"把蓝天变米色"或"把 3812 色压到 1234 色"。

### 5.2 为什么不能靠后处理实现

实测（对 v6 输出做后处理）：

| 变体 | distinct colours |
|---|---|
| v6 原样 | 2560 |
| v6 量化到 32 级 | **2560（无变化）** |
| v6 量化到 16 级 | 559 |
| v6 局部均值 3×3 | 30（变灰） |

**量化到 32 级完全不减少颜色数** —— "减少颜色多样性"**必须由训练学会**。

## 6. 正确的训练方向

### 方案 A：颜色分布损失（**首选**）

```python
# 目标：匹配风格参考图的颜色分布，而非仅均值
# 1) 分位数匹配（对 R/G/B 各自的分位数）
q_levels = [0.1, 0.25, 0.5, 0.75, 0.9]
loss_quant = sum(F.l1_loss(torch.quantile(y[:,c], q, dim=(1,2)),
                           style_quant[c][q])
                 for c in (0,1,2) for q in q_levels)

# 2) 颜色汇聚（降低输出颜色多样性）
#    对输出做 soft 量化，奖励像素向少数中心聚集
palette = soft_quantise(y, n_centers=32)          # 可微
loss_palette = F.l1_loss(y, palette)              # 或熵惩罚
```

**预期收益**：

| 指标 | v6 | 目标（官方） |
|---|---|---|
| distinct colours | 2560 | **1234** |
| entropy | 8.66 | **7.85** |
| flat share | 23% | **5%** |
| 天空 R−B | −3.0 | **+25.1** |

### 方案 B：条件颜色约束（修天空）

天空的问题是**条件性**的：高亮度 + 低饱和 + B>R 的区域应转暖。

```python
# 对"天空类"像素（高亮度、蓝占优）施加暖化约束
sky_mask = (lum(y) > 0.7) & (y[:,2] > y[:,0])
loss_sky = ((y[:,0] - y[:,2])[sky_mask] - 25/255).clamp(min=0).mean()
```

**注意**：这需要小心，避免把真正的冷色物体也暖化。

### 方案 C：保持已修好的部分

**不要回退的项**：

| 项 | 保持值 | 理由 |
|---|---|---|
| 二次色调 | `-0.6375x² + 1.2662x + 0.1281` | R² 0.980；v5 的仿射给出 ratio 1.001 |
| identity | **真实画作，权重 10** | v7 降到 2 后暗场恶化（66.3 vs 58.1） |
| 训练分辨率 | **512** | v5/v6 损失显著优于 256（ratio 0.497 vs 0.734） |
| 层权重 | `[0.3, 0.5, 1.4, 1.8]` | 偏向深层（低频） |

### 方案 D：不需要做的

| 项 | 结论 |
|---|---|
| **head=2（3×3 头）** | ❌ **不必要** —— 教师 RF 9 已优于官方 RF 7；问题是损失不是架构 |
| 改 RTL | ❌ 不需要 |
| 扩大数据集 | ❌ 已是官方全量（7863 文件逐字节相同） |
| 降 identity 权重 | ❌ 已验证更差 |

## 8. 关键事实备忘

### 部署约束（RTL 实测）

| 项 | 值 |
|---|---|
| 输入通道上限 | 24（`row0lo`+`row0hi` = 192 bit） |
| 输出通道上限 | 32（`co_group` 2 bit × 8 路） |
| 非深度 3×3 | **ci 只能是 3**（`rgb_terms` 硬编码） |
| 深度 3×3 | 任意（按 8 分组） |
| 1×1 | ci ≤ 24 |
| 系数 ROM | 256 字/bank，权重+归一化共用 |

### 资源与帧率

| 项 | 值 |
|---|---|
| 当前 XLR | 57,870 / 60,800（95.18%） |
| RAM | 256 / 256（100%） |
| DSP | 140 / 160（87.5%） |
| 帧率 | **10 fps** @ 9,056,056 周期 |
| 有效 MAC/周期 | 22.5（远低于 96 路峰值） |

### 数据

| 项 | 值 |
|---|---|
| 官方数据集 | 与我们**逐字节相同**（7863 文件） |
| trainA（浮世绘） | 562 |
| trainB（照片） | 6287 |
| 官方文档声称 1433，**实际 825（含 testA）** | 文档不准 |

### 教师 vs 学生

| | 教师 | 学生 |
|---|---|---|
| 第一层 | **Conv9×9 stride 1** | Conv3×3 **stride 2** |
| 感受野 | **RF 9** | — |
| 参数 | 1,383,555 | 8,251 |
| 是否部署 | ❌ 仅离线参考 | ✅ 上板 |

**关键**：教师不受 RTL 限制，所以可以用宽卷积；学生必须遵守 RTL。

---

## 9. 一句话总结

**问题不在笔触、不在架构、不在数据 —— 在于损失函数只约束了颜色的均值和方差，
从未约束颜色的分布。加一条颜色分布损失，是最高性价比的下一步。**
