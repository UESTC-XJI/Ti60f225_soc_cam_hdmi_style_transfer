# AE响应与小高光防抽动调整

2026-10-09。配套FPGA仍为`../software_3a/software_3a.bit`；下载本目录或`software/firmware/build/`的soc_video_app.elf。此前i2c_fix产物保留。本版未由agent下载或配置板卡，防抽动实际效果待用户加载确认。

## 实板依据

用户重配bit后确认AE开始工作，但固定光线下小块高亮光源导致抽动。只读COM4确认RAW/RESIZE30、DISP60、DROP/ERR0，AE/AWB计数更新且code/err0。旧控制器高光>10‰无条件减曝光，即使平均亮度偏暗，也会与后续增曝光冲突。最新保存UART为稳定无高光场景，exp2989/mean88/hot0；它证明采集和控制无错误，不是小高光抽动的直接波形记录。

## 调整

- 高光柔化亮度目标：默认96，超过10‰每增加4‰降低1，最低72；不因少量饱和光源一直压暗主体。
- 大误差比例调整、单步0.5～2倍；中小误差半幅/四分之一修正。
- 误差±4进入保持，保持后±8内不动；细调连续3份有效统计在同一方向才执行。明显光照变化立即粗调。
- 保留曝光合法范围、真实I²C错误、Group Hold、3+delay帧确认、AWB版本协调与capture fault保护。UART增加goal/hold，观察稳定后AE计数是否停止增长。
- 不实现50/60Hz曝光量化，不改变VTS、PLL、模拟gain或RTL。

## 验证

实际RV32 ELF的3A与完整main测试PASS。独立延迟生效30FPS模型：初始曝光200与7103分别在13/27帧（约0.43/0.90秒）进入目标±4；不是实板响应保证。固定场景±7噪声及孤立±10扰动无曝光写入，持续亮度漂移仍能退出保持。小光源0.8～1.4%阈值波动、持续5%高光、AE/AWB耦合增益变化均收敛且稳定后不再写曝光。曝光上下限、3802所有延迟、故障注入、旧启动、驱动与IDE配置检查PASS。详细结果见camera_3a_runtime.json和firmware_runtime.json。

text=11464、data=4、BSS=528，BIN=11468字节。文件校验值见manifest.json。原bitstream与旧release不变。

## 实板复查

停止IDE调试，重新配置原software_3a.bit，再加载本版ELF/F8运行一次，以避免已知热重载采集fault。固定镜头和照明，依次观察无光源、小高亮光源、遮挡/移开光源与明暗切换；确认RAW/RESIZE30、DROP/ERR0、code/err0，曝光稳定后AE更新停止。若state7，先恢复硬件故障；不要屏蔽检查。实际防抽动效果尚未确认。
