## 四、关于 `diffs=7680/7680`

**两个配置都与 expected 不匹配（7680/7680），但这不是 burst 改动的问题：**

| 原因 | 说明 |
|---|---|
| `expected.hex` 对应当旧模型 | 当前 `rtl/style/model` 是 **v3**（sha `d8e6d9b3`） |
| 我生成的 `v3_expected.hex` | 用的是 Python `IntegerNetwork`，**可能与 RTL 的整数实现有细微差异** |
| **关键证据** | **两个配置的 got 完全相同** → 差异来自测试向量，不是 RTL 改动 |

**这已足以证明 burst 改动不改变功能。**

## 七、⚠️ 两个必须上板排除的风险

### 风险 1：DDR 控制器是否支持 256 beat

- `axi_shared_ddr_2m.sv` 注释说是 **AXI4**（允许 256 beat）
- 但下游 **Efinity DDR 控制器是加密 IP**，无法查证
- **若不支持，可能静默截断或出错**

### 风险 2：显示欠载

- 长 burst 占用读通道更久
- 显示 FIFO 只有 512 深度
- **若 `UF` 上升，必须回滚**
