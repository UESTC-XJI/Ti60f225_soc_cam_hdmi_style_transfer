## 四、为什么 v3 成功而 v2 失败

| | v2 | v3 |
|---|---|---|
| `dark_hf` | **开启 200**（硬掩码 + 空掩码死梯度） | **删除** |
| `contrast` | **固定 0.1176**（远低于输入 std 0.252） | 自适应 0.65 |
| `grain` | 800（未校准） | **550**（扫描校准） |
| 结果 | 发散射向全白 | **稳定且命中目标** |

**v2 的失败链条**（已实测）：contrast 固定低值奖励压平 → 暗部消失 → `dark_hf` 掩码变空 → **梯度恒零** → 无法拉回 → 模型"成功"满足全部标量约束。

**v3 的修正恰好切断了这条链**：删除死梯度项 + contrast 改为自适应。
