## 二、R2 失败的根因（已实测，非推测）

### 关键实验

构造两张图：**逐通道亮度分布几乎相同，但饱和度差 0.2203**。

| 图 | 饱和度 | R 通道分位数 |
|---|---|---|
| 灰图 | **0.0000** | [0.049, 0.250, 0.497, 0.747, 0.949] |
| 彩色图 | **0.2203** | [0.048, 0.249, 0.497, 0.749, 0.952] |

**量化损失 L1 = 0.000923**（几乎为零），而**饱和度差 0.2203**。

**→ `quantile` 项匹配的是"逐通道亮度分位数"（形状 `(3, L)`），
对通道**间的差异**是盲的。一个饱和像素和一个灰像素可以有相同的逐通道亮度分布。**

### 为什么这不是权重问题

| 项 | 作用 | 能否压饱和 |
|---|---|---|
| `quantile 0.3` | 逐通道亮度分位数 | ❌ **盲**（实测） |
| `tone 300` | 亮度均值/std | ❌ 通道盲（v1 已去掉 cast，但 tone 只有标量） |
| `style 1500` | VGG Gram | ❌ VGG 特征 mean/std 归一化（项目文档已记录其对全局色调盲） |
| `contrast-ratio 0.45` | 输出 std 目标 | ❌ 只约束亮度离散度 |
| `cast 0` | 通道偏移 | ◐ 已关闭 |

**结论：v1 的损失集里【没有任何一项读取饱和度】。**
**提高 quantile/style 权重不能解决 —— 必须新增一项。**

### 域分离度（证明这个轴值得加项）

| | 饱和度均值 | std |
|---|---|---|
| 水墨 A（469 张） | **0.0224** | 0.0163 |
| 照片 B（600 张） | **0.3887** | 0.1529 |

**分离度 3.4σ** —— 轴是可分的，只是没有损失项读它。

## 三、v2 方案

### 3.1 新增：饱和度项（核心）

```python
# sat(image) = mean over pixels of (max_c - min_c) / max_c
mx = y.max(1).values; mn = y.min(1).values
sat = ((mx - mn) / mx.clamp_min(1e-6)).mean()
sat_loss = F.mse_loss(sat, sat.new_full(sat.shape, TARGET))
```

**目标值**：用**损失自身的公式**在数据集上实测
（本项目已因"目标用不同统计量测量"踩坑 4 次）。

**关键设计：必须双侧 + 配对比度项**
- **单侧** `relu(sat - target)` 在目标以下无梯度 → 无法把饱和压下去（平庸）
- **单侧** `relu(target - sat)` 会推向**全灰泥**（饱和=0 但丢失墨/纸对比）
- **必须双侧**，且**与对比度项配合**：因为"黑墨+白纸"和"灰泥"**都是低饱和**，
  只有对比度能区分它们。v1 已有 `contrast-ratio 0.45`，需确认它足够。

### 3.2 保留 v1 已达标项

| 参数 | 值 | 状态 |
|---|---|---|
| `--cast-weight` | **0** | ✅ R1 的关键，必须保留 |
| `--contrast-ratio` | 0.45 | ◐ 需复核（见 3.1） |
| `--grain-weight / target` | 550 / 0.0418 | ✅ v3 扫描实测 |
| `--identity-weight` | 3 | ✅ |
| `--dark-hf-weight` | 0 | ✅（v2 发散元凶，不得重开） |
| tone 300 / quantile 0.3 / style 1500 | 沿用 | — |

### 3.3 权重初值（待 A/B 确定）

| 项 | 初值 | 说明 |
|---|---|---|
| `--sat-weight` | **200**（待 A/B） | 新增项；v1 的 sat 偏差是 0.202−目标，需足够拉力 |

**必须先 A/B 扫描**（v1 的教训：grain 期望 405、实测需 550，线性插值不准）。
