## 三、决定性证据：右半 72.6% 相邻像素完全相同

### 3.1 检验方法

取右半内容区（`x=980..1900`, `y=200..880`），统计**相邻列像素**的差异：

- `diff = |R(x)-R(x+1)| + |G(x)-G(x+1)| + |B(x)-B(x+1)|`
- `完全相同` = diff == 0

### 3.2 结果

| 版本 | 右半 σ | 相邻差异均值 | **完全相同比例** |
|---|---|---|---|
| **左半原画（基准）** | **64.0** | **6.9** | **29.3%** |
| **v4 修复后** | **9.9** | **2.6** | **72.6%** |
| redsky_q（v3） | 13.4 | 2.1 | 63.1% |
| 星空 g075 | 7.1 | 4.3 | 37.2% |
| 早期（双重 XOR） | 16.7 | 1.7 | 65.4% |

**v4 修复后，右半 72.6% 的相邻像素完全相同 —— 是原画（29.3%）的 2.5 倍。**

### 3.3 为什么排除「显示端拉伸」

**一开始怀疑右半被水平拉伸（640→1280），几何检查排除了这个可能：**

| 检查项 | 值 | 判定 |
|---|---|---|
| `img_x0` / `img_x1` | 260 / 1540 | — |
| 总宽 | 1280 | = 640 × 2 ✅ |
| 左半范围 | 260..900 = **640 列** | ✅ 1:1 映射 |
| 右半范围 | 900..1540 = **640 列** | ✅ **1:1，不拉伸** |
| `expect_x` | `h−img_x0` → 0..639 / 640..1279 | ✅ 与 `x` 计数匹配 |

**`x` 计数器生命周期也验证过：**

| 阶段 | 行为 | 判定 |
|---|---|---|
| 行开始（IDLE） | `x<=0` | — |
| 第 1 次读（原画） | x 0→639 | ✅ 匹配 `expect_x` 0..639 |
| 第 2 次读（风格） | x 640→1279 | ✅ 匹配 `expect_x` 640..1279 |

**`style_display` 的几何逻辑完全自洽，没有 bug。**

因此 **72.6% 的相邻重复只能来自风格图内容本身** —— 输出在空间上是低频的（大面积同色）。

## 四、两个问题的严格区分（本次最重要的结论）

| 问题 | 指标 | 修复前 | v4 修复后 | 状态 |
|---|---|---|---|---|
| **① 数值量程不足** | INT8 值 σ | 13–15 | **33–37** | ✅ **已解决** |
| **② 空间平坦** | 相邻像素差异 | 2.1 | **2.6** | ❌ **未解决** |
| | 相邻相同比例 | 65% | **72.6%** | ❌ **未解决** |

**模型侧报告验收的 σ（50–55）是【像素值的一维分布离散度】。**
**但它不衡量【空间变化】—— 一个全屏渐变但每行相同的图，σ 可以很大而视觉上依然平坦。**

**当前 v4 正是这种情况：值的分布铺开了（σ 33–37），但相邻像素之间几乎没有差异（72.6% 完全相同），所以视觉上仍是一块块的色斑，看起来泛白。**

## 五、模型侧下一步该查什么

### 5.1 最强怀疑：输出层空间过度平滑

rowpipe 网络最后一层是 **3×3 卷积**（见 `rowpipe_keys/rtl/accel_rowpipe/style_network_rowpipe.sv` 的 L11 描述符 `mk(4, 3, 640,480,640,40, ...)`）。

可能的原因：

| 原因 | 说明 |
|---|---|
| **感受野过大** | 12 层全 3×3，等效感受野很大，输出天然低频 |
| **缺少高频约束** | 训练 loss 只约束像素值（L1/感知），没有梯度/高频项 |
| **上采样方式** | L9/L10 是 up2 转置卷积，可能过度平滑 |
| **最后几层通道太窄** | L11 只有 3 通道输出，中间层 8 通道，容量有限 |

### 5.2 建议的检查顺序（成本从低到高）

1. **看训练 loss 里有没有高频项**
   如果只有 `L1 + 感知 + 风格`，输出必然偏平滑。加一个 **TV loss 的逆**（负相关项）或**梯度匹配项**：
   ```python
   grad_x = out[:, :, :, 1:] - out[:, :, :, :-1]
   grad_y = out[:, :, 1:, :] - out[:, :, :-1, :]
   loss_hf = -(grad_x.abs().mean() + grad_y.abs().mean())  # 或匹配输入的梯度
   ```

2. **对比训练集输出与推理输出的空间统计**
   在训练集上算 `相邻像素差异` 和 `σ`，与板侧实测对比。如果训练集上就已经是 72% 相同，那是模型本身的性质；如果训练集上好而板侧差，那是量化/导出丢了高频。

3. **检查 up2 层（L9/L10）的实现**
   转置卷积 + 最近邻插值会产生块状重复（正是 72.6% 那个模式）。若用的是 nearest，改成 bilinear 或加一次轻量卷积。

4. **看最后一层之前是否缺少 1×1 提升**
   L11 是 `ci=4 → cout=3` 的 3×3，通道很少。可以考虑在它之前插一个 1×1 升维再降维。

### 5.3 验收指标（补充到原报告 §6）

| 指标 | 当前 | 目标 |
|---|---|---|
| INT8 值 σ | 33–37 | ≥ 45 ✅（已接近） |
| **相邻像素差异均值** | **2.6** | **≥ 5.5**（原画 6.9 的 80%） |
| **相邻完全相同比例** | **72.6%** | **≤ 35%**（原画 29.3%） |
| 显示后右半 σ | 9.9 | ≥ 35 |

**注意最后两行是新增的 —— 原报告只验收了前三行里的第一行，漏掉了空间维度。**
